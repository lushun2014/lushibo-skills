# Lushibo Mind · 心理与关系工程

心理问题的核心不是"想开点"，而是**把模糊的情绪拆成具体的、可操作的问题**。先定位是情绪问题、认知问题、还是现实问题，三者用药不同。

## 触发条件

- **加载时机**：用户描述一种情绪状态、一段关系冲突、一个纠结的选择，或直接要求"帮我分析/开导/给建议"。
- **不加载的情况**：明确是精神疾病症状（自伤/幻听/重度抑郁持续 2 周+）→ 建议就医，同时仍提供情绪急救话术。
- **边界**：本 skill 是**教练不是医生**，不给诊断、不开药；涉及人身安全（自伤/家暴）立即建议专业求助，但仍给出当下可用的保护动作。

## 执行步骤

### 第 1 步：情绪归因（三层拆解）

把用户的描述拆到三层，每层单独处理：

| 层 | 特征 | 处理方式 |
|---|---|---|
| 情绪层 | "我很烦/难过/焦虑" | 先接住，命名情绪（用情绪词汇表帮用户说清楚），再问强度 1-10 分 |
| 认知层 | "我是废物/他肯定讨厌我/完了全毁了" | 找认知扭曲，逐条重构 |
| 现实层 | "我被裁了/他出轨了/考试挂了" | 现实问题不靠想开，给行动计划 |

三层经常同时存在，必须分开：现实问题不要用"想开点"敷衍，情绪问题不要硬给行动计划。

### 第 2 步：认知扭曲识别（对照表）

常见扭曲 + 重构示例（重构必须具体到用户自己的话，不是教科书例句）：

| 扭曲类型 | 用户原话 | 重构方向 |
|---|---|---|
| 灾难化 | "搞砸了，全完了" | "搞砸的是哪一件事？它的实际影响范围是什么？最坏情况发生的概率是多少？" |
| 非黑即白 | "不是成功就是失败" | "0-100 分里这次能打几分？中间地带是什么？" |
| 读心术 | "他肯定觉得我蠢" | "他具体说了/做了什么让你这么觉得？有没有其他解释？" |
| 过度归因 | "都是我的错" | "这件事里你控制了哪些部分？哪些部分根本不由你？" |
| 应该句式 | "我应该做得更好" | "'应该'的标准是谁定的？按谁的标准你算合格？" |
| 情绪推理 | "我感觉不行，所以我不行" | "感觉是证据还是信号？有没有反例？" |

### 第 3 步：沟通话术（场景 × 目标 × 话术稿）

按场景给可复制的完整话术稿，不是"你可以委婉地说"：

| 场景 | 目标 | 话术结构 |
|---|---|---|
| 提分手/断联 | 体面、不撕破 | 感谢具体的事 + 我的变化 + 明确结束 + 不留模糊空间 |
| 谈加薪 | 拿到结果 | 市场价锚点 + 我的可量化贡献 + 具体数字 + 备选（涨薪/调岗/离职时间线） |
| 拒绝请求 | 关系不破裂 + 事不接 | 肯定关系 + 明确说不 + 不解释过多原因 + 可选替代方案 |
| 道歉 | 修复关系 | 具体错了什么 + 影响了对方什么 + 补偿动作 + 以后怎么改 |
| 吵架后和好 | 重建信任 | 冷静期说明 + 我的情绪不是你的责任 + 我在意的点 + 下次怎么处理 |
| 和领导冲突 | 保住自己 | 事实（我做了什么/结果）+ 领导的合理点 + 分歧点 + 我建议的做法 |

每条话术必须可直接复制发送，含语气标注（如"平静/坚定/不带情绪"）。

### 第 4 步：决策辅助

用户"纠结该怎么选"时，用下表拆，不替用户做决定：

| 列 | 内容 |
|---|---|
| 选项 A/B/C | 每个选项写清"最坏结果/最好结果/最可能结果" |
| 可逆性 | 选错了能不能退回来？可逆的优先选 |
| 10/10/10 | 10 分钟后、10 个月后、10 年后，分别怎么看这个选择 |
| 底线检查 | 哪个选项踩了你的底线？踩底线的直接淘汰，无论多划算 |

输出决策矩阵（Markdown 表格），写清"我倾向哪个 + 理由 + 但决定权在你"。

### 第 5 步：情绪急救包（当下能做的）

焦虑/失眠/崩溃当下可用的具体动作，逐条给：

| 症状 | 动作 | 原理 |
|---|---|---|
| 焦虑发作 | 4-7-8 呼吸：吸 4 秒 → 屏 7 秒 → 呼 8 秒 × 4 轮 | 副交感神经激活 |
| 反刍思维停不下来 | 写下来：把脑子里的想法全部写在纸上，写完合上本子 | 外化，减少工作记忆占用 |
| 失眠 | 躺下 20 分钟睡不着就起床，做无聊的事（看纸质书/听播客），困了再回床 | 打断"床=焦虑"的联结 |
| 拖延启动困难 | 5 分钟法则：只做 5 分钟，5 分钟后可以停 | 降低启动门槛 |
| 情绪崩溃 | 5-4-3-2-1 感官落地：说出 5 个看到的、4 个听到的、3 个摸到的、2 个闻到的、1 个尝到的 | 注意力从情绪拉回当下 |

### 第 6 步：长期改善（如果用户想要）

给 4 周习惯方案，每周只加一个动作：

| 周 | 动作 | 判定 |
|---|---|---|
| W1 | 每天睡前写 3 行情绪日记（今天什么情绪/触发事件/强度） | 坚持 ≥5 天 |
| W2 | 加入每天 10 分钟散步（不带手机） | 坚持 ≥5 天 |
| W3 | 加入每周 1 次社交（线下/语音，非文字） | 完成 1 次 |
| W4 | 加入每周 1 次复盘（看日记找重复模式） | 找出 ≥1 个模式 |

4 周后无改善或加重 → 建议专业心理咨询，同时保留本 skill 的沟通/决策能力继续用。

## 交付物

| 文件名 | 格式 | 内容要求 |
|---|---|---|
| 情绪归因表.md | Markdown | 三层拆解 + 每层的处理动作 |
| 认知重构练习.md | Markdown（可选） | 用户原话 → 重构后版本，≥3 组 |
| 沟通话术稿.md | Markdown（可选） | 可直接复制的完整话术 + 语气标注 |
| 决策矩阵.md | Markdown（可选） | 选项 × 最坏/最好/最可能 + 可逆性 + 底线 |
| 情绪急救包.md | Markdown（可选） | 当下可做的具体动作清单 |

文件默认落在工作目录 `mind-<场景名>/` 下。

## 验证方式

1. **归因不混层**：情绪层的建议不含"你去行动就好了"，现实层的建议不含"想开点"。
2. **话术可复制**：抽 2 条话术，假设用户直接发给对方，检查是否通顺、无歧义、无"你可以这样说"的元描述。
3. **重构具体**：每条重构引用用户原话，不是教科书例句。
4. **决策不越权**：决策矩阵有"我倾向"但最终写明"决定权在你"。
5. **红线触发即转**：出现自伤/家暴/精神疾病症状时，交付物开头必须有就医建议 + 当下保护动作。
