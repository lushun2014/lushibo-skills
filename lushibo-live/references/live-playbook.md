# 直播执行细则：话术 / 场控 / 节奏 / 漏斗 / 复盘

本文件是 `lushibo-live` 的模板与参数库。

## 1. 逐字稿模块模板

### 1.1 开场钩子（15 秒，3 版）

```
A（福利型）：刚进来的别划走，今晚前 20 分钟上一款 9.9 的 <品名>，就这个时间段有。
B（痛点型）：买过三四个都坏了的扣 1，今晚这款我现场拆给你看内部结构。
C（人设型）：做了 8 年 <行业>，今天第一次把 <品类> 的出厂价摆出来讲。
```

### 1.2 痛点共鸣（30 秒）

结构：`你是不是 <具体处境> → 结果 <具体损失> → 所以需要 <标准>`

```
你是不是买过好几个，用两周就松了、掉漆了、充不上电？
最后全堆在抽屉里，加起来也花了两三百。
所以挑这个我只认三条：材质、结构、售后。
```

### 1.3 产品讲解（90 秒）

顺序固定，不许跳：**参数 → 场景 → 对比 → 演示**

```
参数：整机 220 克，容量 500 毫升，316 不锈钢内胆，保温 12 小时实测 58 度。
场景：通勤装一杯、办公室放一天、带娃出门冲奶粉都够。
对比：普通款是 304，厚 0.3 毫米，这款 316，厚 0.5 毫米，摔一下不会凹。
演示：我现在倒 95 度水，两小时后我们再测一次。
```

### 1.4 信任背书（30 秒）

```
销量：这个型号我们卖了两万三千多单。
资质：检测报告在公屏，编号 <编号>。
售后：7 天无理由，1 年只换不修，运费我们承担。
```

### 1.5 逼单（30 秒）

```
原价 199，今晚 99，库存 200 件，卖完链接下架。
3、2、1，上链接。
不喜欢直接退，运费我出，你不用担风险。
```

### 1.6 循环拉回（20 秒，每 5-8 分钟一次）

```
刚进来的说一下，现在讲的是 <品名>，今晚 <价格>，库存还剩 <数量>，
前 20 分钟的福利还在，先点关注别错过。
```

## 2. 场控口令表

| 口令 | 执行岗位 | 动作 | 回执 |
|---|---|---|---|
| 上链接 | 场控 | 上架指定 SKU 并置顶 | "已上" |
| 下架 | 场控 | 下架当前 SKU | "已下" |
| 放券 | 场控 | 发放指定优惠券 | "券已放，剩余 N" |
| 改价 | 场控 | 改价到指定金额 | "已改" |
| 加库存 | 场控 | 库存 +N | "库存 N" |
| 开福袋 | 助播 | 开福袋并口播 | "福袋已开" |
| 投流加预算 | 中控 | 按 ≤30% 幅度加预算 | "已加，花费 X" |
| 投流停 | 中控 | 暂停计划 | "已停" |
| 私信承接 | 客服 | 承接公屏/私信咨询 | "已私信" |

## 3. 开播前 Checklist（T-30 分钟）

- T-30：网络双线测速、备用 4G/5G 热点就绪
- T-25：设备电量 >80%、麦克风试音、补光灯色温
- T-20：链接逐个上架测试、价格与库存核对、优惠券可用性验证
- T-15：福袋与抽奖设置、公屏欢迎语、脚本卡打印或分屏
- T-10：投流计划已建（含测试预算）、素材已上传待审
- T-5：私域预告已发、短视频挂载直播已设置
- T-0：开场钩子第一句

## 4. 流量与投流参数

| 参数 | 参考值 | 说明 |
|---|---|---|
| 冷启动测试预算 | 300-500 元/场 | 用于测素材与人群 |
| 单次加预算幅度 | ≤30% | 超过易触发模型重学 |
| 加预算触发条件 | 连续 15 分钟转化率高于基准 20% | 数据驱动，不凭感觉 |
| 停投触发条件 | 30 分钟 ROI <1 | 先查素材与人群 |
| 自然流/付费流配比 | 7:3（成熟期）；5:5（起量期） | 自然流占比过低说明内容不行 |
| 预告视频发布时机 | 开播前 2 小时 | 给平台留推荐时间 |

## 5. 转化漏斗基准

| 环节 | 基准区间 | 低于基准的第一动作 |
|---|---|---|
| 曝光→进入 | 3%-10% | 换封面、改直播标题 |
| 进入→停留 60 秒 | 30%-50% | 重写前 30 秒钩子 |
| 停留→互动 | 10%-25% | 增加提问、抽奖、点名 |
| 互动→商品点击 | 15%-35% | 提高讲解与口播链接频率 |
| 点击→下单 | 5%-20% | 补信任证据、调价格、明示库存 |
| 下单→支付 | 60%-90% | 催付话术、简化支付路径 |

UV 价值 = GMV ÷ 场观。提升 UV 价值只有两条路：提高客单价（套装/加赠）或提高转化率。

## 6. 复盘字段口径

| 字段 | 口径 |
|---|---|
| 场观 | 本场累计进入人数（去重） |
| 峰值在线 | 最高同时在线人数及其出现分钟 |
| 平均停留 | 总观看时长 ÷ 场观 |
| 互动率 | 评论+点赞+分享人数 ÷ 场观 |
| 商品点击率 | 商品点击人数 ÷ 场观 |
| 下单率 | 下单人数 ÷ 商品点击人数 |
| 支付率 | 支付订单 ÷ 下单订单 |
| GMV | 支付口径成交额（不含退款） |
| UV 价值 | GMV ÷ 场观 |
| 退款率 | 退款额 ÷ GMV（T+7 回看） |
| 投流 ROI | 投流带来的成交额 ÷ 投流花费 |

## 7. 异常处置

| 异常 | 处置 |
|---|---|
| 在线人数骤降 | 立即切换福利款 + 投流加预算 20% |
| 链接被下架 | 场控切备用链接，主播不中断讲解 |
| 库存售罄 | 立即切下一个 SKU，同时预告返场时间 |
| 恶意刷屏 | 助播拉黑 + 公屏引导，主播不复述负面词 |
| 设备/网络中断 | 30 秒内切备用设备，中控同步发公告 |

## 8. 使用边界

平台直播规则、广告投放资质与话术合规要求随平台政策变化，执行前以平台最新规则为准。
