# 变现模型库与测算细则

本文件是 `lushibo-money` 的参数库。设计路径、算账、定价时按需查表，所有数字都是可替换的行业参考值，不是结论。

## 1. 变现模型速查

| 模型 | 收入结构 | 现金流特征 | 启动门槛 | 规模化瓶颈 |
|---|---|---|---|---|
| 一次性外包 | 单笔固定价 | 回款快、波动大 | 会做 + 有样品 | 人力上限，必须涨价或分包 |
| 按效果分成 | 底价 + 分成 | 回款慢、上限高 | 能拿到数据口径 | 归因争议、甲方拖延 |
| 数字产品 | 单价 × 销量 | 前期投入大，边际成本近 0 | 有流量入口 | 流量成本，盗版 |
| 订阅制 | MRR | 最稳，但流失率吃掉增长 | 持续交付能力 | 内容枯竭，churn |
| 广告分成 | CPM/CPC × 曝光 | 平台政策风险 | 稳定流量 | 单价由平台决定 |
| 佣金带货 | 成交额 × 佣金率 | 与选品强相关 | 信任基础 | 退货率、佣金结算周期 |
| 咨询/陪跑 | 小时或按次 | 客单价高、时间重 | 有可验证案例 | 不可复制，必须产品化 |
| 授权/白标 | 授权费 + 分成 | 一次性谈判 | 有成熟资产 | 需要法务与交付支持 |

## 2. 成本项穷举清单

漏项会让模型虚高 20%-60%。逐项核对：

**交付成本**
- 人力：工时 × 时薪（时薪按"你愿意接的最低时薪"填，不要用理想值）
- 分包：外包单价 × 数量
- 素材：字体/图片/音视频素材授权费
- 软件：设计、剪辑、云服务器、API 调用费

**获客成本**
- 付费流量：广告消耗 ÷ 成交数
- 内容制作：脚本、拍摄、剪辑工时折算
- 样品与试用：免费样品成本 × 送出数量 × 转化率倒数
- 渠道返点：给介绍人/渠道的 10%-30%

**平台成本**
- 平台抽成：电商 2%-8%，内容平台 5%-50%，应用商店 15%-30%
- 支付手续费：0.6%-1%
- 提现与汇兑：跨境 0.5%-3%
- 退款率：按客单价 × 退款率计入成本

**固定成本**
- 工具订阅、场地、设备折旧、宽带与代理、税费（增值税/所得税按当地税率）

**隐性成本**
- 沟通与返工：按交付工时的 20%-35% 计提
- 账期占款：账期天数 ÷ 30 × 月固定成本
- 学习成本：进入新领域的爬坡期

## 3. 关键公式

```
单件毛利      = 客单价 − 单件可变成本
毛利率        = 单件毛利 ÷ 客单价
LTV(一次性)   = 单件毛利 × 平均购买次数
LTV(订阅)     = 单件毛利 ÷ 月流失率
LTV/CAC       = LTV ÷ 获客成本
CAC回收周期(月) = CAC ÷ 月均毛利贡献
盈亏平衡销量   = 月固定成本 ÷ 单件毛利
每千次曝光收入 = 1000 × 点击率 × 转化率 × 客单价
目标月利润     = 销量 × 单件毛利 − 固定成本
```

反推公式（先定目标再定结构）：

```
所需销量   = (目标月利润 + 固定成本) ÷ 单件毛利
可承受CAC  = LTV ÷ 3
最高成本   = 客单价 × (1 − 目标毛利率)
```

## 4. 行业参数基准（2024-2026 观察值，仅作锚点）

| 项目 | 常见区间 | 备注 |
|---|---|---|
| 知识付费课程毛利率 | 70%-90% | 主要成本是获客 |
| 软件外包毛利率 | 30%-50% | 人力密集，规模不经济 |
| 实物电商毛利率 | 20%-45% | 退货率 5%-30% |
| SaaS 月流失率 | 2%-8% | 中小企业客户偏高 |
| 私域加微通过率 | 20%-45% | 强信任场景可到 60% |
| 社群转化率 | 1%-5% | 冷流量更低 |
| 直播成交转化 | 1%-8% | 与客单价强负相关 |
| 信息流广告 ROI | 1.2-3.0 | 低于 1.2 通常亏 |
| 转介绍返佣 | 10%-20% | 低于 10% 基本无动力 |

## 5. 定价三法取交集

1. **成本加成**：`价格 = 成本 ÷ (1 − 目标毛利率)`。注意是除以 (1−毛利率)，不是乘以 (1+毛利率)。
2. **锚点对比**：取 3 个同类竞品中位数，上浮 10%-30%，并明确写出"多给的 3 件事"。
3. **价值定价**：客户因此多赚或少花的钱 × 10%-30%。

三层价格带同时存在时转化率最高：

| 档位 | 作用 | 定价策略 |
|---|---|---|
| 引流档 | 建立信任、筛客户 | 接近成本价，限量 |
| 主力档 | 贡献 70% 利润 | 成本加成 + 锚点 |
| 高端档 | 做背书、拉高锚点 | 价值定价，限量接单 |

## 6. 漏斗基准与诊断

| 环节 | 基准 | 偏低时先改什么 |
|---|---|---|
| 曝光→点击 | 2%-6% | 标题与首图，不动正文 |
| 点击→留资 | 10%-25% | 落地页信息密度与信任证据 |
| 留资→首次沟通 | 50%-80% | 24 小时内触达，超时腰斩 |
| 沟通→成交 | 5%-20% | 报价结构、案例、风险逆转 |
| 成交→复购 | 10%-40% | 交付后 3 天回访 + 下一阶段钩子 |

只优化当前最低的一层。同时改多层无法归因，等于没改。

## 7. 需求验证打分表

每项 0-2 分，总分 <6 分不做：

| 项 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 主动询价人数（24h） | 0 | 1-2 | ≥3 |
| 有人愿意付定金 | 无 | 犹豫 | 已付 |
| 竞品是否在卖同类 | 没有 | 有但很弱 | 有且活得不错 |
| 你能否 1 周内交付 | 不能 | 勉强 | 能且有余量 |
| 交付后能否复用 | 不能 | 部分 | 可模板化 |

## 8. 常见亏钱结构（发现即改）

1. 毛利率 <30% 却靠"走量"——量越大，现金流越紧。
2. CAC 用广告费除以"咨询数"而不是"成交数"——真实 CAC 被低估 3-10 倍。
3. 把一次性收入当 MRR 做规划——第二个月归零。
4. 定价按"我觉得值多少"，没有竞品对照。
5. 免费试用无门槛、无期限——试用者永远不会付费。
6. 忽略账期：利润表好看，现金链断裂。

## 9. 使用边界

本 skill 只提供商业测算与执行方法论。涉及具体经营主体时，税务、合同与资质要求以当地法规和专业顾问意见为准。
