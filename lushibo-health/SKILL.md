# Lushibo Health · 健康与体能工程

健康管理是**行为工程**，不是知识科普。核心：先测基线，再定一个 4 周可执行的最小方案，跑完再调。禁止一开始给"完美计划"——执行不下去的计划等于没有计划。

## 触发条件

- **加载时机**：用户给出目标（减脂/增肌/改善睡眠）、体检报告、体测数据，或描述症状/习惯问题要求方案。
- **不加载的情况**：明确医学症状（胸痛/持续疼痛/异常出血）→ 建议就医，本 skill 只给就医前的注意事项。
- **边界**：本 skill 是**教练与翻译**，不是医生。体检解读只做"指标分层与生活建议"，不做诊断、不替代医生意见，交付物必须写明"以医生诊断为准"。

## 执行步骤

### 第 1 步：测基线

能测什么就测什么，缺了用估算（写明是估算）：

| 基线项 | 获取方式 | 用途 |
|---|---|---|
| 体重 / 腰围 | 秤 + 软尺 | 减脂/增肌的进度指标 |
| 体脂率（估） | 腰围÷身高估算 或 体脂秤 | 判断减脂还是增肌优先 |
| 每日步数 | 手机 | 活动量基线 |
| 睡眠时长 | 自报 / 手环 | 作息方案起点 |
| 静息心率 | 晨起测 1 分钟 | 有氧强度参考 |
| 体检报告 | 用户提供 | 指标分层 |

### 第 2 步：定 4 周最小方案

原则：每次只改 1-2 个行为，4 周后复盘再加。禁止一次改 5 个（执行率归零）。

**减脂方向默认方案**：

| 变量 | 动作 | 判定 |
|---|---|---|
| 饮食 | 每餐蛋白质 = 手掌大小 ×1，主食减半，含糖饮料归零 | 每周体重降 0.5-1kg |
| 运动 | 每周 3 次力量（全身）+ 每日步数 +3000 | 力量动作重量或次数周环比增长 |
| 睡眠 | 固定起床时间（周末偏差 ≤1h），睡前 1h 不看手机 | 入睡时间 <30min |

**增肌方向默认方案**：

| 变量 | 动作 | 判定 |
|---|---|---|
| 训练 | 每周 3-4 次分化或上下肢分化，每个动作 3-4 组 × 6-12 次 | 每周重量或次数 +2.5% |
| 饮食 | 蛋白质 1.6-2.2g/kg 体重，热量盈余 +300-500kcal | 每周体重 +0.25-0.5% |
| 恢复 | 睡眠 ≥7h，训练肌群间隔 ≥48h | 无持续性关节疼痛 |

### 第 3 步：训练计划（具体到动作/组次/进阶）

新手全身 3 天模板（可按用户情况调整）：

| 日 | 动作 | 组×次 | 备注 |
|---|---|---|---|
| A | 深蹲（或箱式深蹲）| 3×8-12 | 先徒手，能标准 15 次再加负重 |
| A | 俯卧撑（或跪姿）| 3×8-15 | 做不到 8 次退阶到上斜 |
| A | 划船（弹力带/哑铃）| 3×10-15 | 背部发力，不耸肩 |
| A | 平板支撑 | 3×30-60s | 腰不塌 |
| B | 硬拉（或罗马尼亚）| 3×8-10 | 髋铰链，腰背平直 |
| B | 推举（哑铃）| 3×8-12 | 站姿或坐姿 |
| B | 弓步蹲 | 3×每边10 | 膝盖方向对脚尖 |
| B | 死虫式 | 3×每边8 | 腰贴地 |

进阶规则：**动作能标准完成当前次数上限 → 下次加重量 2.5-5% 或加 1-2 次**。疼痛（非酸胀）即停，换动作。

### 第 4 步：饮食结构（克数化，不抽象）

按体重算，给出每餐具体参考：

| 项 | 计算 | 示例（70kg 减脂） |
|---|---|---|
| 蛋白质 | 减脂 1.6-2.0g/kg；增肌 1.6-2.2g/kg | 112-140g/天 → 每餐 35-45g |
| 碳水 | 减脂 2-3g/kg；增肌 3-5g/kg | 140-210g/天 |
| 脂肪 | 0.8-1g/kg | 56-70g/天 |
| 蔬菜 | ≥500g/天 | 每餐一拳 |
| 水 | 30-40ml/kg | 2.1-2.8L |

蛋白质来源优先级：鸡蛋 / 鸡胸 / 鱼虾 / 瘦牛猪 / 豆制品 / 乳清。外卖选择规则：有明确蛋白质（鸡腿/牛肉/鱼）+ 主食减半 + 不喝含糖饮料。

### 第 5 步：睡眠改善

| 优先级 | 动作 | 原理 |
|---|---|---|
| 1 | 固定起床时间（含周末） | 锚定生物钟 |
| 2 | 晨起 30min 内见光（出门/窗边） | 皮质醇节律 |
| 3 | 睡前 1h 调暗灯光，手机出卧室 | 褪黑素 |
| 4 | 卧室温度 18-22°C | 深睡比例 |
| 5 | 咖啡因 14:00 后不摄入 | 半衰期 ~5h |

### 第 6 步：体检报告解读（分层，非诊断）

把用户提供的指标按下表分层，逐项给"生活建议 + 是否需复查/就医"：

| 层级 | 判定 | 动作 |
|---|---|---|
| 正常 | 参考范围内 | 维持 |
| 临界 | 超出参考范围 ≤20% | 3 个月生活方式干预后复查 |
| 需复查 | 超出 20%-2 倍，或明显异常项 | 2-4 周专科复查 |
| 需就医 | 显著异常（如转氨酶 >3 倍、血糖空腹 ≥7.0） | 尽快专科就诊 |

常见指标速查：转氨酶（ALT/AST）、血脂四项（TC/LDL/HDL/TG）、血糖（空腹/糖化）、尿酸、肌酐、甲状腺（TSH/FT3/FT4）、血常规。每项给出该指标升/降的常见原因（饮食、运动、疾病）。

**交付物末尾必须写**：以上分层为生活参考，非医学诊断，具体以医生意见为准。

### 第 7 步：习惯养成

按"提示-行为-奖励"三要素设计，每周只加 1 个习惯：

| 习惯 | 提示设计 | 判定 |
|---|---|---|
| 戒含糖饮料 | 把饮料放看不见的地方 + 桌上常备水杯 | 连续 7 天零含糖饮料 |
| 戒烟 | 设定戒烟日 + 告知身边人 + 替代动作（口香糖/深呼吸） | 连续 7 天 0 支 |
| 久坐管理 | 每 50 分钟起立活动 2 分钟（设闹钟） | 每日 ≥6 次起立 |

## 交付物

| 文件名 | 格式 | 内容要求 |
|---|---|---|
| 训练计划表.md | Markdown | 动作/组次/进阶规则，≥4 周 |
| 饮食结构表.md | Markdown | 每日宏量营养素克数 + 每餐参考 + 外卖规则 |
| 睡眠改善清单.md | Markdown（可选） | 按优先级排序的动作清单 |
| 体检指标分层表.md | Markdown（可选） | 每项：数值 / 分层 / 建议 / 是否复查 |
| 习惯追踪表.csv | CSV（可选） | 日期 × 习惯 × 完成情况 |

文件默认落在工作目录 `health-<目标名>/` 下。

## 验证方式

1. **训练可执行**：动作均为常见动作，无需特殊器械（或已注明替代动作）。
2. **进阶规则明确**：写清"什么时候加重量/次数"，不是"逐渐增加"。
3. **饮食有克数**：蛋白质/碳水/脂肪都换算成每日克数与每餐参考。
4. **体检分层有边界**：每项建议都注明"以医生诊断为准"，未做诊断性结论。
5. **方案最小化**：初始方案同时改变的行为 ≤3 个，4 周后才加新的。
