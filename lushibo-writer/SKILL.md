# Lushibo Writer · 写作工程

写作的核心是**信息密度和节奏**，不是文采。先定"给谁看、要对方看完后做什么/感受到什么"，再动笔。没有目标读者的写作等于没有任务。

## 触发条件

- **加载时机**：用户给出主题、大纲、初稿、或"帮我写/改"的指令，且产出物是文字作品（小说/文章/文案/公文/演讲稿）。
- **不加载的情况**：纯技术文档走 `$docs-generator`；营销落地页+转化结构走 `$lushibo-ecom`；直播口播走 `$lushibo-live`。
- **边界**：本 skill 管**文字作品本身**，不管发布平台运营（那是 ecom/live 的事）。

## 执行步骤

### 第 1 步：定目标（30 秒完成）

写之前先回答三个问题，答案写进交付物开头：

| 问题 | 要具体到 |
|---|---|
| 读者是谁 | 年龄/身份/阅读场景（地铁刷手机 / 办公室看邮件 / 睡前读书） |
| 读者看完后做什么 | 下单 / 转发 / 改变看法 / 记住一个观点 / 付钱 |
| 篇幅与格式 | 字数、平台限制、是否分段、是否要配图 |

缺答案时按最常见可逆默认处理（社媒帖=500 字/短剧脚本=3 分钟/公文=标准格式），不追问。

### 第 2 步：定结构（先骨架后血肉）

四类文章的默认结构：

| 类型 | 结构 | 关键节奏点 |
|---|---|---|
| 故事/小说 | 起（钩子）→ 承（冲突升级）→ 转（意外/反转）→ 合（回收+余韵） | 前 3 行必须制造悬念或情绪 |
| 观点/公众号 | 钩子 → 反常识观点 → 论据 1/2/3 → 边界/让步 → 行动号召 | 第 1 段 ≤3 行，每段 ≤4 行 |
| 公文/报告 | 结论先行 → 依据 → 细节 → 风险 → 请示/建议 | 第一句话就是结论 |
| 文案/脚本 | 注意力钩子（0-3 秒）→ 痛点/欲望（3-10 秒）→ 方案（10-30 秒）→ 行动号召（30-60 秒） | 钩子决定 80% 成效 |

### 第 3 步：信息密度检查

逐段打分（1-5 分，5 分最高）：

| 维度 | 5 分 | 1 分 |
|---|---|---|
| 信息增量 | 删掉这段读者损失具体东西 | 删掉没影响 |
| 具体度 | 有数字/人名/场景/动作 | 全是抽象形容（"很好""非常棒"） |
| 推进力 | 读完想知道下一句 | 读完想跳过 |
| 情绪/逻辑 | 情绪递进或逻辑链完整 | 重复或断裂 |

任何段落 <3 分即重写。全文平均 <3.5 分则整篇重写，不是润色。

### 第 4 步：成稿

一次写完，不写半截。禁止以下写作习惯：

| 禁止 | 原因 | 替代 |
|---|---|---|
| "本文将从以下几个方面讨论" | 浪费读者 5 秒 | 直接给第一个论点 |
| "总之/综上所述" 结尾堆砌 | 信息量为 0 | 结尾给一个具体动作或反问 |
| 全文无一个具体数字/场景 | 空洞 | 每段至少 1 个可验证细节 |
| 网文开篇写天气/环境 | 读者 3 秒划走 | 开篇写人物冲突或悬念 |
| 公文用"我" | 不正式 | 用"本部门/本次/现将" |

### 第 5 步：改稿诊断

用户提供初稿时，按下表逐项诊断，每项给出**改前→改后**的具体例句：

| 检查项 | 判定标准 | 常见病灶 |
|---|---|---|
| 钩子 | 前 3 行是否制造了悬念/冲突/情绪 | 开篇背景铺垫过长 |
| 结构 | 是否有清晰的"起承转合"或"结论先行" | 段落之间无递进关系 |
| 信息密度 | 平均分 ≥3.5 | 重复、抽象、凑字数 |
| 语言 | 是否有 >30 字的长句（拆短） | 一句话三个逗号 |
| 口吻 | 与目标读者匹配 | 给 00 后用 80 后用语 |
| 结尾 | 是否有行动号召/记忆点 | 突然断掉或重复前文 |

### 第 6 步：模板复用

每次交付后，把可复用的结构（开头钩子模板、过渡句库、结尾模板）并入交付物「写作模板.md」（可选交付，见下表），下次同类任务直接调。

## 交付物

| 文件名 | 格式 | 内容要求 |
|---|---|---|
| 成稿.md | Markdown | 完整可发布文本（非大纲、非片段） |
| 改稿诊断表.md | Markdown（改稿时） | 每项含改前例句→改后例句 |
| 写作模板.md | Markdown（可选） | 本次可复用的钩子/过渡/结尾模板 |

文件默认落在工作目录 `writing-<项目名>/` 下。

## 验证方式

1. **成稿完整**：全文 ≥ 目标字数的 90%，无 TODO/占位符。
2. **钩子有效**：截取前 3 行给一个未看过主题的人，能回答"接下来会发生什么/你想让我干什么"。
3. **信息密度达标**：抽 3 段逐项打分，平均 ≥3.5。
4. **无禁用句式**：全文搜索"本文将从""综上所述""总之"，命中即重写。
5. **格式匹配平台**：微信公众号段落 ≤4 行、短视频脚本 ≤60 秒（约 180 字）、公文标题层级 ≤3 级。
6. **诊断可落地**：改稿诊断表的每条"改后例句"可直接替换进原文，不含"建议优化一下"这类空话。
