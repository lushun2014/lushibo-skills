# Lushibo Learn · 学习工程

学习设计的核心是**前置依赖排序 + 间隔重复 + 输出驱动**，不是"多花时间"。先确认目标（能用/考过/精通），再倒推路径。

## 触发条件

- **加载时机**：用户给出一个要学的技能/一场考试/一个学习卡点，要求给计划或诊断。
- **不加载的情况**：纯技术问题（这个 bug 怎么解）走对应技术 skill；职业规划走 `$lushibo-money` 的资产盘点。
- **边界**：本 skill 管**学习过程设计**，不管具体知识内容的讲解（内容讲解由对应领域 skill 承担）。

## 执行步骤

### 第 1 步：定目标（SMART 压缩版）

三个问题，缺一不可，缺了就用可逆默认：

| 问题 | 可逆默认 |
|---|---|
| 目标是什么（能用/考过/精通） | "能用" |
| 截止时间 | 3 个月 |
| 每周可投入时间 | 10 小时 |

### 第 2 步：前置依赖排序

把要学的东西拆成知识点/技能点，画出依赖图，按"学了马上能用"排序。禁止线性学完整本教材再动手。

示例（学 Python 数据分析）：

```text
周 1: Python 基础语法（只学到函数）→ 产出：能写脚本读 CSV 并统计
周 2: pandas 核心 API（读/筛选/分组）→ 产出：清洗一份真实脏数据
周 3: matplotlib/seaborn → 产出：3 张能看懂的图
周 4: 完整小项目 → 产出：一份带结论的分析报告
```

每阶段必须有产出物，不是"学完第 X 章"。

### 第 3 步：间隔重复设计

新学的内容按 1 天 / 3 天 / 7 天 / 14 天 / 30 天复习，工具用 Anki 或手写卡片。禁止"只在考前复习"。

卡片制作规则：

| 规则 | 要求 |
|---|---|
| 一卡一事实 | 一张卡只问一件事 |
| 问句形式 | 正面是问题，不是知识点标题 |
| 自己写 | 不直接抄书上定义，用自己话写 |
| 数量控制 | 每天新卡 ≤20 张，复习卡不限 |

### 第 4 步：输出驱动

每学一个模块，必须做一次输出（选一即可）：

| 输出形式 | 要求 | 判定 |
|---|---|---|
| 费曼笔记 | 假装讲给 12 岁小孩听，写 300 字 | 无专业术语、无循环定义 |
| 做题/实践 | 做 3-5 道题或写一个小 demo | 正确率 ≥70% |
| 写文章/教程 | 写一篇"我怎么学会 X 的" | 发出去或至少公开存档 |

只输入不输出 = 学了就忘的主因。

### 第 5 步：卡点诊断

| 卡点 | 常见原因 | 处理 |
|---|---|---|
| 记不住 | 没有间隔重复，或卡片太大 | 改卡片粒度 + 建 Anki 每日复习 |
| 学不动 | 内容跳级（前置没学好） | 往前找第一个"懂但做不出题"的节点，回去重做 |
| 坚持不下去 | 目标太大 / 没有短期反馈 | 缩小到每天 15 分钟 + 每周产出物 |
| 看得懂做不出 | 只输入没输出 | 强制做 3 道题/写一个 demo，不许看书 |
| 学了没用上 | 学的内容和目标脱节 | 回到第 2 步重新排序 |

### 第 6 步：时间表

按用户可投入时间排每周时间表，格式：

| 时段 | 周一 | 周二 | ... | 周日 |
|---|---|---|---|---|
| 早 30min | 新卡 | 新卡 | | 复盘 |
| 晚 60min | 实践 | 看课 | | 输出 |

原则：每天必有输出，每周必有产出物，每 2 周一次复盘调整计划。

## 交付物

| 文件名 | 格式 | 内容要求 |
|---|---|---|
| 学习路径.md | Markdown | 分阶段，每阶段含产出物 + 判定标准 + 预估时长 |
| 每周时间表.md | Markdown | 时段 × 星期，含每日输出动作 |
| 卡点诊断表.md | Markdown（可选） | 卡点 → 原因 → 处理动作 |
| Anki 卡片清单.csv | CSV（可选） | 正面/背面/标签，可直接导入 |

文件默认落在工作目录 `learn-<主题名>/` 下。

## 验证方式

1. **阶段有产出**：每个阶段都写了"产出物是什么"，且产出物可验证（不是"理解了"）。
2. **依赖排序合理**：第一阶段的知识足以完成第一阶段的产出物，不需要后面阶段的内容。
3. **时间表可执行**：每天投入时间之和 ≤ 用户声明的每周时间。
4. **有间隔重复**：路径里明确包含复习节奏（1/3/7/14/30 天或等价机制）。
5. **有输出要求**：每阶段至少一种输出形式，且写了判定标准。
